# Registro de cambios del complemento SNMP3

# 25/07/2026

- Posibilidad de definir una tarea programada independiente en el motor de tareas
- Cifrado de las contraseñas en la base de datos
- Mejora de la gestión de las tareas programadas

# 16/06/2026

- Definición de los métodos cron en «static» para evitar errores en PHP 8 (modificaciones perdidas durante una actualización)

# 01/01/2026

- Traslado de la documentación a un repositorio de GitHub independiente para poder actualizarla sin que ello implique una actualización del complemento
- Eliminación de los avisos de PHP

# 28/03/2025

- Incorporación de una comunidad RW (normalmente «privada») para las actualizaciones en los protocolos v1/v2c

# 17/10/2024

- Definición de los métodos cron como estáticos para evitar errores en PHP 8
- Corrección de un error en los comandos de actualización
  
# 11/08/2024

- La gestión de los reintentos ahora la lleva a cabo directamente el complemento y no la biblioteca Net-SNMP

# 20/02/2024

- Carga inicial
